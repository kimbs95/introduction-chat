# 김병성 소개

## 자기소개
김병성은 Java, Spring, MySQL, REST API 개발을 중심으로 일하는 백엔드 개발자입니다. 서버 개발, 성능 최적화, 확장 가능한 아키텍처에 관심이 있습니다.

## 주요 기술 스택
주요 기술 스택은 Java, Spring Boot, Spring, SQL, MySQL, REST API, Docker, Linux입니다. JavaScript와 React를 사용한 프런트엔드 개발 경험도 있습니다.

## DevOps 관심 분야와 학습
개발과 운영을 연결하고 싶어 DevOps를 학습하고 있습니다. CI/CD 파이프라인, Docker, Kubernetes, AWS, GCP, 인프라 자동화에 관심이 있습니다.

## 앞으로의 목표
장기적인 목표는 시니어 개발자로 성장한 뒤 DevOps 전문성을 갖추는 것입니다. 시스템 아키텍처, CI/CD, 클라우드, 컨테이너 오케스트레이션 역량을 깊이 있게 발전시키고자 합니다.

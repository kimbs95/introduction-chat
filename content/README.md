# 자료 관리

- 화면의 이름·소개·연락처: `profile.json`
- 챗봇이 참고할 공개 자료: `documents/` 아래 파일
- 기본 `about.md`는 제공한 자기소개를 바탕으로 작성했습니다. 실제 이력서로 바꿔 주세요.
- `documents/` 안의 지원 파일은 하위 폴더까지 모두 읽습니다. 비공개 파일은 이 경로와 공개 저장소에 넣지 마세요.
- 이 폴더의 README는 챗봇에 포함되지 않습니다. `documents/` 안에 넣으면 포함됩니다.
- 이름, 이메일 등 `profile.json` 내용도 챗봇 지식에 반영됩니다. 위 소개와 문서가 서로 모순되지 않게 관리하세요.
- 추가/수정/삭제 후 `main`에 커밋하면 Actions가 전체 지식을 다시 생성합니다.
